# Gia công – app cài được (PWA)

Trang nhỏ bọc app Google Apps Script "Giao nhận gia công" để cài lên điện thoại như ứng dụng.
Phần mềm thật nằm trên Google, cập nhật app không cần đổi gì ở đây.

- `dev/` – bản DEV (link Apps Script cố định của file DEV)
- `_icon/icon.html` – nguồn vẽ biểu tượng (chụp bằng Chrome headless)
